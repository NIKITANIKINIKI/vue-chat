# Веб-чат с голосовым вводом

Современное веб-приложение для обмена сообщениями в реальном времени с поддержкой голосового ввода и современного интерфейса.

## 🔹 Описание проекта

Проект построен на **Vue 3** с Composition API и **Pinia** для управления состоянием, что обеспечивает высокую производительность и удобное расширение функционала.

**Ключевые особенности:**

1. **Голосовой ввод с Web Speech API** — пользователь может диктовать сообщения, которые автоматически распознаются и отправляются в чат.  
2. **Универсальные компоненты** — кнопка микрофона, поле ввода и область сообщений реализованы через слоты и события (`defineProps`/`defineEmits`), что делает их легко переиспользуемыми.  
3. **Красивый кастомный скролл и плавная прокрутка** — приятный пользовательский опыт при работе с длинными списками сообщений.  
4. **Гибкая архитектура** — события и состояние отделены от визуальных компонентов, упрощая интеграцию с различными источниками данных и API.  
5. **UX-фокус** — анимации кнопок, визуальная индикация записи голоса и отзывчивый интерфейс делают взаимодействие интуитивным.

> Приложение подходит как для личного использования, так и для интеграции в корпоративные платформы обмена сообщениями.

---

## ⚡ Технологии

- Vue 3 + Composition API  
- Pinia для управления состоянием  
- Node.js для бекенда  
- Web Speech API для голосового ввода  
- Lucide / Heroicons для иконок  
- Tailwind CSS для стилей

## 🚀 Инструкция по запуску

### 1️⃣ Настройка переменных окружения
Создайте файл `.env` в корне проекта и добавьте ключ Hugging Face:

```env
HF_TOKEN=ваш_ключ

2️⃣ Запуск бекенда

Перейдите в папку с серверной частью:

cd backend
npm install
node index.js


Сервер будет доступен по адресу (например, http://localhost:3000)
3️⃣ Запуск фронтенда

Перейдите в папку с фронтендом:

cd frontend
npm install
npm run dev


Фронтенд откроется в браузере по адресу, который выдаст Vite (обычно http://localhost:5173).

4️⃣ Проверка работы

Откройте фронтенд в браузере.

Отправьте текстовое сообщение или воспользуйтесь голосовым вводом.

Убедитесь, что сервер получает запросы и корректно отвечает.
